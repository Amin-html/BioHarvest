# ADR-004: Authentication — JWT (access+refresh, refresh в httpOnly cookie)

**Context**: SPA (React) + отдельный API-домен (FastAPI на Render).

**Decision**: короткоживущий JWT access token (в памяти на фронте) +
refresh token с ротацией в httpOnly Secure SameSite=Strict cookie.

**Reason**: см. сравнение в SECURITY.md — stateless access token хорошо
масштабируется на несколько backend-инстансов, httpOnly refresh снижает
риск XSS-кражи, SameSite снижает риск CSRF без доп. CSRF-токена.

**Trade-offs**: сложнее logout/revocation, чем у server session (нужна
таблица refresh-токенов и ротация); требует аккуратной реализации на
фронте (single in-flight refresh promise), иначе race condition при 401.
