# ADR-002: ORM — SQLAlchemy 2.x + Alembic

**Context**: FastAPI не диктует ORM.

**Decision**: SQLAlchemy 2.x (declarative, typed) + Alembic для миграций.

**Reason**: де-факто стандарт для FastAPI, полный контроль над query
(select_related-аналоги через joinedload/selectinload), зрелый инструмент миграций.

**Trade-offs**: более многословный синтаксис, чем Django ORM; нет
готовой admin-интеграции; async-режим SQLAlchemy добавляет когнитивную
нагрузку (нужно консистентно использовать AsyncSession).
