# ADR-001: Backend framework — FastAPI

**Context**: нужен backend без Django admin (собственный Admin UI на React),
с явным разделением слоёв, async-friendly для будущей нагрузки.

**Decision**: FastAPI.

**Reason**: Pydantic-валидация из коробки, автогенерация OpenAPI, async
поддержка, тонкие роутеры хорошо ложатся на layered-архитектуру.

**Trade-offs**: нет встроенной admin-панели (нужно строить самим, см.
ARCHITECTURE.md п.19) и нет ORM из коробки — требует отдельного решения
(см. ADR-002). Экосистема моложе Django, часть паттернов (auth, permissions)
нужно строить руками, а не брать готовыми.
