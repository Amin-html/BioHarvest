# ADR-007: Deployment — Render (backend) + Cloudflare Pages (frontend) + Neon (DB)

**Context**: нужен недорогой managed-стек без своего DevOps под Kubernetes.

**Decision**: Render для FastAPI (Docker-based service), Cloudflare Pages
для статики React, Neon для БД.

**Reason**: минимальная операционная нагрузка для одного разработчика,
все три сервиса имеют щедрый free/hobby tier для MVP-стадии, CI/CD из
GitHub Actions нативно поддерживается всеми тремя.

**Trade-offs**: три разных провайдера — три разных панели управления и
набора secrets; нет единого observability-дашборда "из коробки" (нужен
Sentry отдельно для сквозного error tracking).
