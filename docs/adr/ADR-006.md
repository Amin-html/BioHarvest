# ADR-006: File storage — локально (dev) → Cloudflare R2 (production, Future)

**Context**: product images нужно где-то хранить; сравнивались local
filesystem, Cloudflare R2, S3-compatible.

**Decision**: MVP dev — локальный filesystem/volume; production —
Cloudflare R2 (S3-совместимый API) как только появится реальный трафик
с изображениями.

**Reason**: R2 бесплатен на исходящий трафик (важно при CDN-раздаче
изображений), совместим с S3 SDK, легко мигрировать позже — не блокирует MVP.

**Trade-offs**: локальный storage в dev не воспроизводит точно поведение
production (нет CDN-кэширования) — обязательно протестировать загрузку/
удаление на R2 перед объявлением фичи готовой.
